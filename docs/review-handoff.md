# 评审交接入口

`bin/review-auto-worker CONTEXT SETTINGS` 接收公开交接事实，调用本机配置指向的仓库正式评审入口。事件中的 argv、链接和说明不作为命令运行。

SETTINGS 是仓库外、权限 600 的 JSON 文件，父目录权限 700，配置 checkout（评审共享检出绝对路径）、programs（程序登记目录绝对路径）、repository（目标仓库）、event_source（中台来源名称）。不得提交实际配置、身份、密钥或运行记录。

评审接收、验证、去重和收尾逻辑在仓库；中台路由、服务安装、配置与机器间传输留本机。其他本机适配器不因此自动收入仓库。

合并后，操作员将中台固定启动命令改为本入口并传入 context 与设置文件；评审机安装设置并核对共享检出、程序路径和事件来源。不得把事件中的命令直接执行。先在目标环境验收，再替换旧入口；本 PR 不部署机器。

预检读取最多尝试三次。正式模型运行不自动整轮重试。已结束且退出码非零的交接允许同 head 再次提交；成功退出的记录阻止重复。整个正式派发持有全局锁；下一次拿到锁后看到的 started 记录视为中断，可恢复交接。旧失败记录移入新尝试目录保留，不删除历史。
