# Proposal: task-model-roles

用户原话：“你先遵循第一性原理看一下需要怎么改 是你来改云claude审核对吧”。

目标：Codex 修改，云 Claude 独立审核；模型能在不同任务交换实现/审核角色。
本次可审查交付先修已验证的固定限制：已知作者的审核家族按当前任务排除；审核目标仓库和令牌权限贯穿同一个输入。来源继续采用 GitHub 实际推送身份，未经证实的共享账号模型来源保持未知。不能把这份改动称为可信任务溯源或生产隔离已经完成。

验收：登记多个 Builder 家族后，不参与当前实现的家族仍可审核；同家族拒绝；未知、混合来源、高风险预算和旧 HEAD 拒绝条件保留。非默认仓库读取/快照/发布一致；目标不合法、授权超范围或规则缺失拒绝。默认 OpenDesign 调用兼容。

不交付：模型启动平台、claude.ai 自动接口、共享 build 身份的自动模型认证、App 扩权、系统安装、合并或自动放行。它们需要原计划的来源/隔离前提，不靠本次测试宣称完成。

评审预算：最多 2 轮实质评审；目前实现后交云 Claude，额度未恢复时保留未审状态。此时不 PASS 归档，不偷换审查方。
