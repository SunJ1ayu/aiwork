# DS 默认模型单一来源

用户要求 DS 评审腿切换到新模型，并指出此前已约定换模型只改一个地方。
本次将 agent 与 chat 的默认名称统一到 `bin/deepseek-model`，当前值为 `deepseek-flash`。
两条入口的帮助信息从同一文件读取；文档指向配置文件，不再复制版本号。

范围只含模型默认值解析、相关帮助和既有测试的配置夹具。认证、端点、权限、
评审裁决与家族覆盖规则保持原有行为。按 self 验收这个有界的配置重构；
测试用虚构的新默认值验证真实传参，另核对显式覆盖，避免读同一份默认值互相自证。
历史账本的模型名是样例事实，无需随当前默认版本修改。

后续换档只修改 `bin/deepseek-model` 的一行并做冒烟，不再修改执行器、测试或模型说明。
