# Proposal: evidence-lifetime-gate

- Date: 2026-08-13
- Status: open

## Goal

归档那一刻,机械拦下**引用了会话临时目录的 track 工件** —— 要么把证据搬进仓库,
要么在同一行显式认账「仓外不承重」。沉默 = 拒绝归档。

## Motivation

2026-08-13 收 另一个项目 那单时,用户问了一句「刚刚的 track 工作树收尾了吗」。
工作树是干净的(没派执行腿),但顺着查下去发现 design.md 的「规划双出」引的是
`scratchpad/dualplan/codex-plan.log` —— 即 `/tmp/claude-0/-root/<会话id>/scratchpad/`。 [仓外不承重]
**那个会话当天已经断了**,工件还在,它引的证据在 /tmp 里等着被清。

### 这不是孤例 —— 先量后判

扫全机 348 份 track md(aiwork 51 / design-studio 292 / 另一个项目 5),
**22 份引用了 `/tmp` 或 `scratchpad`**。逐行看,分两类: [仓外不承重]

**A. 真证据引用(已经死了或迟早死)**
- `全文在 scratchpad 的 my-review`(**4 处**)—— 主审"读评审腿之前先落盘"的自审。 [仓外不承重]
  它存在的**全部意义就是证明先后顺序**,现在无法核对 ⇒ 退化成我的一面之词。
- `scratchpad/probe_turnid.py`、`scratchpad/probe_noop.py` —— 旁边写着 [仓外不承重]
  「**实测过,不是推演**」,而那个"实测"现在查不到了。
- `driver = scratchpad/e2e_p6.py` —— e2e 驱动脚本,结果进了 verify 但脚本没进仓。 [仓外不承重]
- `scratchpad/brief-date.md` —— 规划双出的中立需求书(**与 另一个项目 这次同形**: [仓外不承重]
  它是"我没把自己的答案先喂给外部腿"的唯一证明)。
- `scratchpad/repro_dup_note.py` —— 「我自己复现证实,不是采信它的自述」的那份复现。 [仓外不承重]

**B. 只是叙述里提了一嘴(不该拦)**
- 「`git worktree list` 里还有另一个会话留在 `/tmp/claude-0/…/wt-base`」—— 在描述一棵野树。 [仓外不承重]
- 日志表格里的 `| 08-06 13:16 | /tmp/tmp.GeK1oSjQNd/repo(建入口时的临时测试仓) |`。 [仓外不承重]
- 另一个项目 design.md 里我自己写的墓碑注释(解释"原路径在 /tmp 下,已搬走")。

**闸必须分得开 A 和 B**,否则它就是噪音 —— 而假报警和假绿一样坏
(08-11 变异脚本三次自己坏了那笔账)。

### 为什么够得上"上机械闸"这一档

按 CLAUDE.md 的准入标准,信任/安全类 = **查工件不查自述 + 防不可逆损害**,
且**允许事前推演准入,不必等出事**:
- 查工件不查自述:死链正是「自述悄悄顶替工件」—— 句子还在、读起来正常、**不报错**,
  只有真去查的那天才发现空了。
- 不可逆:临时目录被清是**回不来的**。
- 已经出过事:上面 A 类 9 处,不是推演。

> ⚠️ 记账:我 08-13 第一版把这条判成「够不上硬规矩」,是**判错了、给它降了档**;
> 是用户追问「用第一性原理了吗」才拆开重判。

## Scope

- 只加**归档那一刻**的一道检查(`track archive`),扫 track 目录下的 `*.md`。
- 命中会话临时目录 ⇒ 拒绝归档,逐条打印 `文件:行号` 与原文。
- 唯一放行方式:**该行自带 `[仓外不承重]` 标记**(逐行,不许一句话打包全放)。
- 判据进 `tests/`,与现有 `test-track-guard.sh` / `test-worktree-sweep.sh` 同形。

## Non-goals

- **不动 pre-commit**。干活期间引用 scratchpad 是正常的(文件还活着), [仓外不承重]
  这条只在"宣布做完"那一刻才成立 —— 与 5b/5c 同样是 archive-mode。
  在提交时也查 = 给活跃工作制造噪音。
- **不追溯已归档的 51+ 个 track**(它们已经归档,闸够不着;死链已成事实)。
- **不试图解析 markdown 里的路径再去 resolve** —— 那是误报的温床。
  改成"提到临时目录就要表态",搬进仓的自然不再提它,**修法本身消除触发条件**。
- 不管非 md 文件(证据文件本身是 .txt/.log,不含引用语义)。

## 第一性:为什么"搬家"这个动作不可消除

根因 = **两个寿命被一行纯文本路径缝在一起,且断了不报错**:
工件活在 git 仓库(寿命 = 项目),隔离目录活在会话临时区(寿命 = 一次会话)。

想彻底消灭"搬家",就得让外部腿**直接写进 `tracks/<name>/evidence/`**。
**这条走不通**:隔离恰恰是靠"那个目录在仓外、只放一个文件"实现的
(见 [[aiwork-worktree-isolation]] 与 delegate 抽屉);让它写进 track 目录,
它就能读到旁边的 design/proposal,**隔离当场破功**。

⇒ 搬家是隔离的**必然代价**,不是补丁。补丁在于:**触发搬家的是我的记性,不是机器。**
