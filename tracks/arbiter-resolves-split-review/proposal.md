# Proposal: arbiter-resolves-split-review

- Date: 2026-09-24
- Status: open

## Goal

同一次评审、同一份交付内容上,合格的腿一家 PASS、一家 BLOCK(下称「分裂」)时,归档闸不再一律作废这次评审;
改由主裁判断。主裁判能过,就必须对 BLOCK 那家的每条意见写清理由和证据,机器查这份记录在不在、全不全,
齐了才把这次评审算进覆盖。

## Motivation

design-studio `opendesign-kimi-glm-vendors` 09-24 空转:第 11 轮修完后产品代码零改动,又派了三次评审。
第 12 轮重派时 DeepSeek PASS、MiMo BLOCK,MiMo 的阻断理由是「测试挡不住假想的错误改法」「0.98.9 就有的老行为」
这类(verify.md #59~#63)。按现行闸,分裂 = 覆盖不算,主裁驳回也没用;反而两家都 BLOCK 时主裁能裁。
⇒ 一条总挑边角的腿手里握着实际否决权,比主裁还大,只能一轮轮重派。

## 真问题(第一性)

- 用户原话(09-24,业主):
  - 「大白话说一下刚刚的审查是不是审查腿都在找边缘情况所以一直在绕圈呢」
  - 「你是主裁决，你如果是这种有人拿锤子砸墙墙会不会裂这种情况你应该直接否决啊」
  - 「好就按这个规定吧，主要是一家通过一家不通过需要你来判断 你觉得可以过就写清理由和证据没错的」
- 真正要解决的是:主裁是唯一仲裁者(CLAUDE.md),但闸在分裂时把裁决权交给了「腿之间是否一致」。
  要让分裂回到主裁手里,同时不回到「一句话推翻 BLOCK」「重抽评审直到全 PASS」(09-22 设这道闸要挡的两件事)。
- 我在这中间翻译了什么:
  - 「写清理由和证据」→ 对 BLOCK 那家**每一条**被驳回/延期的意见各写理由 + 至少一处可查证据(仓内文件/行、runlog 收据);
    机器只查结构与证据存在,不评判理由好坏(与现有 premise_attack 同一种「只查结构」)。
  - 「一家通过一家不通过」→ 同一 run、同一 subject digest 下合格腿里同时有 PASS 与 BLOCK。两家都 BLOCK 已经由主裁裁,不变。
  - 裁决记录写在评审之后,不能因为写它就让这次评审的绑定作废(否则又逼出一轮重派)。
- 用户可观察的成功:下次出现分裂,主裁逐条写清理由和证据后能直接归档;没写、漏写某条腿、证据指向不存在的东西 ⇒ 归档照样挡,
  并说清缺什么。

## Scope

- in:`bin/track-record`(归档覆盖检查 + ledger)、`bin/_review_delivery.py`(交付投影对裁决记录的豁免)、
  decision.json schema v2 的 `outcome` 增加可选字段、`tests/test-track-record.sh` 等判据、panel 抽屉与 CLAUDE.md 里讲冲突的句子。

## Non-goals

- 机器判断理由写得好不好;改 panel-review 选腿、预算数、腿的 PASS/BLOCK 口径。
- 两家都 BLOCK、UNKNOWN/超时/降级/跨 run 拼接/同家族凑数 —— 现行规则一字不动。
- 不回头改已归档 track 的记录。

## 验收边界与轮次预算(要外审的单开工就写 —— panel 抽屉 4b)

- 这一单承诺:
  1. 分裂 + 完整裁决记录(覆盖该组每条 BLOCK 腿,每条意见有理由与存在的证据,outcome.verdict=PASS)⇒ 该组算覆盖;
  2. 分裂而记录缺失 / 漏腿 / 多写不存在的腿 / 指向不存在的 run 或 subject / 意见缺理由或证据 / 证据路径不存在或越出仓库 ⇒ 仍 BLOCK,打印 rule/path/actual/expected;
  3. 评审后写裁决记录不改变交付指纹(与 outcome.verdict 同类豁免),改 decision.json 其它字段照旧改变指纹;
  4. ledger 能看出哪些覆盖是「主裁裁过的分裂」(不藏);
  5. 其余覆盖规则行为不变(现有判据全绿)。
- 不承诺:「测试挡不住任意未来的错误实现」;机器理解理由。
- 实质评审上限:2 轮。impact=high(判卷控制面)。第 2 轮主要核验修复;用完有阻断就保持未完成,
  不自动续轮,延期项留在 verify.md、不自动开新单。**每轮派发前先跑 `track preflight arbiter-resolves-split-review`。**
  复审题面只问本单是否引入缺陷与承诺是否兑现;「挡不住假想实现」类照报不算 BLOCK(业主 09-24 定)。
