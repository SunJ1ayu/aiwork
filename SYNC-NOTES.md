# aiwork web mirror

This private repository is a curated snapshot of the local `/root/aiwork` workspace for ChatGPT access. Its first commit intentionally has no local Git history.

Included: workflow scripts, templates, tests, task briefs, track documents, and the current README.

Excluded: local credentials and configuration, logs, attack logs, generated evidence and observations, worktrees, the `refs` archive (including third-party UI source), and local Git history.

Changes made only in `/root/aiwork` are not visible here until this mirror is updated and pushed.
